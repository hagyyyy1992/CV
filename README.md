## 概要

2017年からWebアプリケーション開発に携わり、**TypeScript・Python・PHPを用いたバックエンドを主軸に、要件整理からDB・API設計、画面実装、テスト、リリース・運用改善まで**担当してきました。請求・入金管理などデータの整合性が求められる業務機能、求人推薦サービスの検索データ整備、大規模データ処理の経験があります。

直近の採用・仕事体験プラットフォームでは、営業上の課題を起点にブロックエディタを提案。方式・費用・運用負荷の比較と試作から、**30種類以上のブロックを備えたエディタの実運用・顧客提供**まで進めました。Claude Code・Codexを日常的に活用し、要件の具体化、AIへの実装指示、テストと実画面での確認、修正・リリースまで対応しています。

GVA TECHではリードエンジニア・PMとして新規サービスの立ち上げ、開発体制の整備、採用・育成を担当。業務委託でも、テックリード不在時のリリース準備やチーム連携を代行してきました。事業側との対話を通じて背景や制約を理解し、実際に提供・運用できる形へ落とし込むことを大切にしています。

2021年に副業として業務委託を開始し、同年9月から独立して稼働を拡大。2025年5月に[Hagyyyy株式会社](https://hagyyyy.com/)を設立し、**Web開発支援と自社アプリの開発・運営**を行っています。代表自身がエンジニアとして開発に入ります。

## これまでの経験・実績

- **提案から顧客提供まで**：営業課題を基にブロックエディタを提案し、方式比較・試作・既存データ移行から制作業務での実運用まで担当。
- **複雑な業務ルールの具体化**：登記手続き、請求・入金、カレンダー・参加費管理などを、データモデル・API・画面・帳票へ反映。
- **データ整合性を保つ設計**：入金・領収書・仕訳・請求更新を、ユースケース単位でまとめて成功・ロールバックできるトランザクション管理へ改善。
- **大量データと性能改善**：約30万行のCSV分割処理、約180万件の通知データ移行、SQL・インデックス改善による画面表示の約30秒から10秒以内への短縮。
- **0→1のサービス立ち上げ**：GVA TECHで企画段階から技術選定・開発・AWS構築・ローンチを担当し、継続開発の体制も整備。
- **開発と品質確認の両立**：Jest・Playwright・CIの整備に加え、チームでの回帰テストを提案・運用し、不具合の検知とリリース判断につなげた経験。
- **AIを活用した開発手順の整備**：カスタムスキル・Git Worktree・複数エージェントを活用し、実装、レビュー、動作確認、修正、リリースの反復手順を整備・共有。
- **チーム運営・採用**：スクラム導入・運用、事業側との開発計画調整、1チームで3プロダクトの開発マネジメント、3名のエンジニア採用を経験。
- **顧客のセキュリティ確認への対応**：実構成の調査、チェックシート・個人情報取扱業務フロー図の作成、WAFの設定是正や運用資料の整備。
